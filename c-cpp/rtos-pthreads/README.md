# Потоки POSIX на C: практики по системам реального времени

[English version](README.en.md)

Практики курса «Вычислительные системы реального времени» (ноябрь–декабрь 2024): многопоточные программы на C с pthreads под Linux.

| Практика | Файлы | Что внутри |
|---|---|---|
| 13 | `1_v1.c`, `1_v2.c` | Два потока выводят сообщения. Во второй версии их чередование задают два мьютекса. Ctrl+C перехватывается обработчиком SIGINT |
| 13 | `2_v1.c`, `2_v2.c` | Симуляция: пять кошек едят корм из общей миски, а хозяин досыпает корм раз в «день» (7 с). Общий ресурс защищён мьютексами |
| 14 | `1.c`, `2.c` | Обедающие философы. В первой версии последний философ берёт вилки в обратном порядке, чтобы не было взаимной блокировки. Во второй философ пытается взять обе вилки: если вторая занята, отпускает первую и ждёт на условной переменной |
| 15 | `main.c` | Производственная линия на семафорах: детали A, B и C изготавливаются параллельно, из них собираются модуль и изделие |
| 16 | `main.c` | Ограниченная очередь сообщений (кольцевой буфер) на семафорах: производители и потребители |

## Запуск

```bash
gcc -pthread practice-14/2.c -o philosophers
./philosophers
```

## Стек

C, POSIX threads (mutex, condition variable, semaphore), сигналы, Linux.

# Лабораторные по C и C++, первый курс

[English version](README.en.md)

Лабораторные и учебные программы первого курса (2022–2023).

## C (`Labs.c`)

Все лабораторные собраны в одном файле: каждая лежит в своём закомментированном блоке со своей функцией `main`. Чтобы запустить одну, раскомментируйте её блок.
- **Массивы:** обработка через указатель и среднее арифметическое элементов.
- **Матрицы:** динамические, со строками разной длины, количество строк и столбцов вводит пользователь.
- **Геометрия:** высота треугольника к выбранной стороне по трём сторонам.
- **Указатели:** адреса массивов и обмен данными между ними.
- **Строки:** выравнивание строки по правому краю.
- **Числа:** факториал и проверка корректности ввода.

## C++

| Файл | Что делает |
|---|---|
| `1703.cpp` | Класс с закрытыми полями, вводом и выводом значений |
| `menu.cpp` | Консольное меню: регистрация персонажа (имя, раса, класс, атака) с сохранением в файл |
| `NewCharacter.cpp` | Класс персонажа с чтением и записью в файлы через `fstream` |

## Запуск

```bash
gcc Labs.c -o labs && ./labs
g++ 1703.cpp -o 1703 && ./1703
```

`menu.cpp` и `NewCharacter.cpp` используют `conio.h`, поэтому собираются под Windows.

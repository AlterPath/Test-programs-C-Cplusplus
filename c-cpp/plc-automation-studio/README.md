# ПЛК B&R в Automation Studio

[English version](README.en.md)

Лабораторная по программному обеспечению мехатронных и робототехнических систем (октябрь 2025): программа на C для контроллера B&R в среде Automation Studio, отлаженная в симуляторе ПЛК. Работа выполнялась в команде.

## Что делает программа

Программа моделирует два двигателя постоянного тока и сравнивает два способа управления:
- **первый двигатель** работает в разомкнутом контуре: напряжение задаётся пропорционально уставке скорости;
- **второй двигатель** работает под ПИ-регулятором (`FB_Regulator`): на вход регулятора подаётся ошибка между уставкой и фактической скоростью.

Уставка меняется ступенькой: на 200-м цикле скорость становится 40, на 400-м сбрасывается в 0, и всё повторяется. По графикам переменных в Automation Studio видно, как оба двигателя отрабатывают ступеньку.

Функциональные блоки лежат в библиотеке `Logical/Libraries/Library`:
- `FB_Integrator`: интегрирование методом Эйлера с шагом 0,01 с;
- `FB_Motor`: двигатель как апериодическое звено, dω/dt = (u/ke − ω)/Tm, где `ke` = 0,24 и `Tm` = 0,1 с;
- `FB_Regulator`: ПИ-регулятор (`k_p` = 0,3, `k_i` = 2,7) с ограничением напряжения ±24 В. Чтобы интегратор не накапливал ошибку при насыщении, разница между ограниченным и исходным выходом возвращается на его вход.

## Два варианта проекта

| Папка | Что внутри |
|---|---|
| `Laba_1/` | Проект целиком: `Init.c`, `Cyclic.c` и `Exit.c` отвечают за инициализацию, циклическую задачу и завершение программы. Рядом лежат настройки отладки и трассировки |
| `Laba_1_refactored/` | Та же лабораторная из командного репозитория (9 октября 2025): инициализация и циклическая задача собраны в одном `Main.c`, функция ограничения называется `VoltageLimitation`, функциональные блоки подписаны |

## Запуск

Откройте `Laba_1/LABA1.apj` или `Laba_1_refactored/LAB1.apj` в B&R Automation Studio 4.5 и запустите конфигурацию `Config1` в симуляторе (ARsim).

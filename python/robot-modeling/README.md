# Моделирование роботов: двухзвенный манипулятор

[English version](README.en.md)

Практика по моделированию роботов (октябрь 2025). Двухзвенный манипулятор со звеньями по 30 см проходит П-образную траекторию 50 × 50 см со скоростью 5 см/с.

`prak_1.py` считает:
- точки траектории по секундам;
- обратную кинематику с двумя решениями (локоть вверх и вниз) и проверку достижимости каждой точки.

| Файл | Что внутри |
|---|---|
| `prak_1.py` | Траектория и обратная кинематика, результат сохраняется в `P_trajectory_utf8.csv` |
| `P_trajectory_utf8.csv` | Координаты точки и углы суставов для обоих решений |
| `pi_trajectory_2link.csv` | Та же таблица с дополнительным столбцом пройденного пути |
| `P_trajectory_plots.html` | Интерактивные графики углов в Plotly |

## Запуск

```bash
pip install pandas
python prak_1.py
```

## Стек

Python, pandas, Plotly.
